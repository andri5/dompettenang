# Dompet Tenang Web

Frontend React + Vite + TypeScript + Tailwind.

Setup, fitur Free/Pro, dan deploy ada di [README root](../../README.md) dan [docs/DEPLOY.md](../../docs/DEPLOY.md).

```bash
# dari root monorepo
npm install
npm run web
```

App lokal: http://127.0.0.1:5173/ — API lewat `VITE_API_URL=/api/v1`.

Gratis di web: pencarian transaksi (catatan atau nama kategori), saldo berjalan, dan pengingat catatan harian.

Halaman Pro yang relevan: `/upgrade`, `/insight` (insight bulanan), dashboard (saran periode berjalan + kartu insight).
